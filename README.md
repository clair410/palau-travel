# Palau｜帛琉南島永續實踐之旅 🏝️

青年百億海外圓夢基金計畫－海外翱翔組 **N-10-3 帛琉南島永續實踐計畫** 專屬行動指南網站。

## 📌 計畫簡介
* **圓夢期間**：116年7月29日至8月12日（為期 15 日，含飛行日）
* **實踐地點**：友邦帛琉（洛克群島、艾萊州、巴貝大島、柯羅州等）
* **核心宗旨**：結合南島文化交流、海洋生態保育（珊瑚礁與硨磲貝復育）、藍碳紅樹林水道與傳統生態智慧（Bul），將在地智慧轉化為青年的永續實踐行動。

## 🚀 網站功能
1. **首頁**：網站名稱、帛琉背景、計畫宗旨、出發倒數計時器及《帛琉誓詞》（Palau Pledge）專區。
2. **行程介紹**：依照官方計畫整理完整 15 日每日考察卡片，支援分類篩選（海洋生態、南島文史、山林水系、青年交流）。
3. **景點導覽**：精選 8 處核心地標與生態景點（洛克群島、石頭錢幣島採石場、紅樹林藍碳水道、安得貌大瀑布、艾萊州男人會館、帛琉珊瑚礁中心 PICRC 等），提供實踐叮嚀並直連 Google 地圖。
4. **行前準備清單**：分類整理必備證件、海洋裝備、田野設備與永續生活用品，即時計算完成進度，透過 `localStorage` 本機保存勾選狀態。
5. **預算記帳**：支援美金（USD）與新台幣（TWD）雙幣別輸入，自動統計總花費與即時匯率換算，儲存於 `localStorage`。
6. **旅程日誌**：提供心情與天氣標籤、日期與多行心得輸入，方便記錄每日田野觀察與反思。
7. **響應式設計**：支援桌面大螢幕與行動版手機介面（含底部專屬導覽列）。

## 🛠️ 技術架構
* **HTML5 / CSS3 / Vanilla JavaScript**（無外部複雜依賴，離線即可順暢運作）
* **低飽和海洋藍綠色系與米白色調**（Teal & Sage, Beige & Sand）
* **Web Storage API (`localStorage`)** 實現無伺服器端的安全本機狀態持久化
